# Metroid Prime 4 PC Recomp

Research project: static recompilation of *Metroid Prime 4: Beyond* (Switch 1 release, ARM64) into a native PC
program, by the method of [totk-pc-recomp](https://github.com/valentderah/totk-pc-recomp) as carried to a second game
by [fe3h-pc-recomp](https://github.com/jaigner-hub/fe3h-pc-recomp).

Status: investigating the game's binaries. Nothing runs yet. The plan is in [docs/plan.md](docs/plan.md).

This repository contains no game content. You need your own copy of the game and keys dumped from your own console.

Third-party code is listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
